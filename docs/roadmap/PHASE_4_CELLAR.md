# Phase 4 — Cellar, Yield and Micro-Costing
Window: Months 10–12 (original target 2027-Q3; provisional). Goal: trustworthy stock/cost records with practical onboarding.

## Work
- Define product, vintage, bottle size, location/bin, lot, movement, reservation, pour and adjustment records with audit/reconciliation.
- Prototype cellar search/bin visualization (e.g. Bin 42 / Shelf B / Bottle 3); test 2D-first before committing to 3D.
- Measure onboarding effort for representative cellar sizes; assess barcode/label-assisted import.
- Track movement/reservations; vintage substitution is a staff-confirmed suggestion with provenance.
- Model recipe, units, yield, trim loss, waste and cost variance for representative ingredients.
- Evaluate Coravin argon, dry-aging, fermentation and waste-scale integrations independently with hardware support requirements.
- Add sommelier flights/tasting journals only with customer demand and privacy rules.

## Exit evidence
Reconcile representative physical inventory; record accuracy, adjustments and onboarding time. Costs trace to quantities, units, yields and prices. Manual fallback for sensor/import failure.

Gate: partner can maintain representative stock/cost data at agreed effort.
